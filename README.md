# 🎵 Skypro.Music

**Skypro.Music** — это веб-приложение для прослушивания музыки, созданное с использованием **Nuxt 3**.  
Оно позволяет искать треки, управлять плейлистом, ставить лайки и сохранять избранное.

---
## 🚀 Основные функции

- ✅ Регистрация и авторизация пользователей
- ✅ Просмотр списка всех треков
- ✅ Фильтрация по исполнителю, жанру и году выпуска
- ✅ Поиск по названию трека
- ✅ Воспроизведение музыки с паузой, переключением, повторением и перемешиванием
- ✅ Добавление треков в избранное (лайки)
- ✅ Личная страница с избранными треками
- ✅ Готовые подборки треков

---
## 🛠️ Стек технологий

| Технология | Назначение |
|------------|------------|
| **Nuxt 3** | Фреймворк для Vue 3 (SSR / SPA) |
| **Vue 3** | JavaScript-фреймворк для UI |
| **Pinia** | Управление состоянием |
| **Vite** | Сборка и разработка |
| **CSS (scoped)** | Стилизация компонентов |
| **Google Fonts** | Шрифты (Montserrat) |
