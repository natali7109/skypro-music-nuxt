# 🎵 Skypro.Music

**Skypro.Music** — это веб-приложение для прослушивания музыки, созданное с использованием **Nuxt 3**.  
Оно позволяет искать треки, управлять плейлистом, ставить лайки и сохранять избранное.

---

## 🚀 Основные функции

   Просмотр списка всех треков
-  Фильтрация по исполнителю, жанру и году выпуска
-  Поиск по названию трека
-  Воспроизведение музыки с паузой, переключением, повторением и перемешиванием
-  Добавление треков в избранное (лайки)
-  Личная страница с избранными треками
-  Приватный доступ к избранному (только для авторизованных)
-  Гостевой режим («Войти без регистрации») с доступом к трекам
-  Стилизованная страница 404
-  Обработка ошибок сервера и пустых состояний

---
### 🔒 Приватные маршруты и гостевой доступ
- **Приватный маршрут:** страница «Мои треки» (`/favorites`) доступна только авторизованным пользователям (редирект на `/login`)
- **Гостевой режим:** на странице входа есть ссылка *«Войти без регистрации»* (серая, при наведении фиолетовая и подчёркнутая) → переход на главную страницу `/tracks`
- **Гостям доступно:** просмотр треков, поиск, фильтрация, воспроизведение
- **Гостям НЕ доступно:** лайки и страница «Мои треки»
- **Блокировка лайков:** при попытке поставить лайк (в списке или плеере) неавторизованный пользователь перенаправляется на `/register` с сообщением: *«Для выбора любимых треков зарегистрируйтесь»*

## 📦 Установка и запуск

### 1. Клонирование репозитория
bash
git clone <url-репозитория>
cd skypro-music-nuxt

2. Установка зависимостей
bash
npm install

3. Запуск в режиме разработки
bash
npm run dev
Откройте http://localhost:3000 в браузере.
